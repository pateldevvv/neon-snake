# Neon Snake

A neon arcade Snake game with swipe controls, particle effects and a saved high score.

## Features
- Swipe controls for mobile, arrow keys for desktop
- Glowing neon visuals and particle explosions
- Speed increases as you score
- High score saved in your browser

## Play
Open `index.html` in any browser.

## Tech
HTML5 Canvas, CSS, JavaScript
